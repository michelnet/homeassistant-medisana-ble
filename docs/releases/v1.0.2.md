# Medisana BLE v1.0.2

This patch release corrects how repeated TM 750 measurements are identified.

## Fixed

- A temperature entity is no longer marked as updated merely because Home
  Assistant reconnected or refreshed optional device information.
- Every received thermometer measurement now updates **Temperature**, **Last
  measurement** and **Last received**, including measurements whose temperature
  and device timestamp equal the previous packet.
- Older device timestamps remain unable to replace a newer reading.

Install the update through HACS and restart Home Assistant. Existing devices,
configuration entries and entity IDs remain unchanged.
