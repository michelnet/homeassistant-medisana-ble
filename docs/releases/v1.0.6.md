# Medisana BLE v1.0.6

- Updates installation instructions for the built-in Marketplace in Home
  Assistant 2026.11 and newer, including adding the repository from a link and
  automatic migration from HACS. HACS instructions remain available for Home
  Assistant 2026.9–2026.10.
- Adds the **Health & wellbeing** integration category for the Marketplace.
- Keeps installation instructions out of the Marketplace's README view while
  retaining device setup and troubleshooting guidance.
- Updates the automated test environment to Home Assistant 2026.11.1 using the
  official Bluetooth test fixtures, and documents Marketplace installation and
  migration checks.

The minimum supported Home Assistant version remains **2026.9.0**. The repository
continues to use `hacs.json` and the HACS validation action, as required by the
Marketplace. Existing devices, configuration entries and entity IDs are preserved.

Install the update through the Marketplace (Home Assistant 2026.11 or newer) or
HACS (older supported versions), then restart Home Assistant. Existing HACS
installations are migrated by Home Assistant; no Medisana BLE reinstallation or
device setup is required.
