# Medisana BLE 1.2.0

This update adds an experimental direct BLE driver for older **PM 150 connect**
oximeters and improves shared-device operation, connection tuning and access to
original measurement records.

- **BS 550 guests:** accept raw user ID 255 as unassigned weight. Ignore guest
  composition placeholders; never assign a personal sensor group.
- **Connection options:** per-attempt timeout, maximum attempts and optional
  pairing. Blood-pressure monitors can synchronize the clock before subscribing
  when required. BSA 45 users can try 3 seconds / 10 attempts; BU 572 users can
  opt into pairing and the alternative clock sequence.
- **Separate user groups:** optional independent sensors for blood-pressure IDs
  0–254 and scale IDs 1–8. Existing main entity IDs and filter behavior are retained.
- **Local records:** retain 200 readings per device by default, configurable from
  0 to 1000. Older and other-user records keep their device/reception timestamps;
  scale enrichment updates one record. Zero disables/purges retention; removing
  the entry removes its record store.
- **CSV and events:** administrator action `medisana_ble.export_history` returns
  CSV. `medisana_ble_measurement` reports received/enriched records, including
  memory downloads. Both include users excluded by the main sensor filter.
- **Diagnostics:** Home Assistant download with firmware, endpoints, settings and
  connection counters; measurements, MAC/serial and legacy UUID identifiers omitted.
- **Research:** older BU 550 standard-profile evidence, PM 150 protocol evidence,
  Android analysis provenance and remaining ViFit/BP Watch/Lefu gaps documented.
- **Documentation:** compact README, detailed device reference and instructions
  for users to test their device and report compatibility with a reusable template.

The legacy oximeter driver and other new behavior have simulated validation;
no additional physical-device test is claimed. BSA 41 remains a candidate without
captured packets. Lefu body-composition SDKs and WLAN-only configuration paths
are not included. No proprietary application code or native library is bundled.

See [device compatibility](../../README.md#device-compatibility),
[protocol research](../PROTOCOL_RESEARCH.md) and [testing](../TESTING.md).

Validation: **204 tests and 873 subtests passed** with Home Assistant 2026.11.1;
Ruff lint/format and whitespace checks passed. The tests include simulated legacy
GATT sessions, guest handling, per-user restoration/replay protection, private
storage, CSV authorization, diagnostic redaction and actual timeout enforcement.
