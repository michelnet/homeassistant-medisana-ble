# Medisana BLE v0.1.0

Introduces **Medisana BLE**, a local Home Assistant integration for Medisana blood
pressure monitors and thermometers using the domain `medisana_ble`.

## Included

- Blood pressure monitor and thermometer discovery, plus manual device-type selection.
- Blood pressure sensors and optional Bluetooth user filter.
- Temperature sensor with optional temperature-type information.
- Shared battery, measurement-time and reception-time sensors.
- Manufacturer, model, firmware, serial number and hardware information when supplied.
- Shared connection sessions, retries, timestamp ordering and state restoration
  for both device types.
- Bundled VitaDock+/Medisana icons and logos.
- English and German setup and entity translations.

## Installation

Requires Home Assistant **2026.9.0 or newer**. Add
`https://github.com/michelnet/homeassistant-medisana-ble` as a HACS custom repository,
or copy `custom_components/medisana_ble` into the Home Assistant configuration
folder, then restart Home Assistant.

## Validation scope

Medisana BLE is covered by automated tests with simulated Bluetooth communication.
It has also completed successful Home Assistant hardware tests with both supported
devices: **BU-570 / BU 570 connect** and **TM 750 connect**. Automatic discovery,
setup and measurement transfer were verified for both. See
[the installation test](../TESTING.md) for the repeatable physical-device checklist.
