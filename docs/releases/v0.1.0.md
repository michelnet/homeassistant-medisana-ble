# Medisana BLE v0.1.0

Combines the Medisana Blood Pressure and Medisana Thermometer integrations into
one integration named **Medisana BLE**, using the Home Assistant domain `medisana_ble`.

## Included

- Blood pressure monitor and thermometer discovery, plus manual device-type selection.
- Blood pressure sensors and optional Bluetooth user filter.
- Temperature sensor with optional temperature-type information.
- Shared battery, measurement-time and reception-time sensors.
- Manufacturer, model, firmware, serial number and hardware information when supplied.
- The blood pressure integration's connection sessions, retries, timestamp ordering
  and state restoration for both device types.
- The blood pressure integration's VitaDock+/Medisana icons and logos.
- English and German setup and entity translations.

## Installation and migration

Requires Home Assistant **2026.9.0 or newer**. Add
`https://github.com/michelnet/homeassistant-medisana-ble` as a HACS custom repository,
or copy `custom_components/medisana_ble` into the Home Assistant configuration
folder, then restart Home Assistant.

Disable the previous `medisana_blood_pressure` or `medisana_dsas` entries for the
same devices and add them again under **Medisana**. Configuration entries, entity
IDs and Recorder history are not automatically migrated. Update references in
dashboards, automations and scripts after verifying the new readings. See the
[README](../../README.md#switching-from-the-separate-integrations) for the steps.

## Validation scope

The combined integration is tested with simulated Bluetooth communication. The
separate source integrations report BU-570 / BU 570 connect and TM 750 connect
hardware testing; those results do not constitute a physical test of this merged
version. Follow [the installation test](../TESTING.md) to check both device types
on real hardware.
