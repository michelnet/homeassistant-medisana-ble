# Medisana BLE v1.0.1

This patch release fixes repeated thermometer measurements whose numeric value
has not changed.

## Fixed

- Every accepted temperature measurement now creates a Home Assistant state
  update, even when the temperature equals the previous reading.
- The sensor's `last_updated` time and state-based automations therefore reflect
  consecutive measurements with the same value.
- Exact duplicate Bluetooth packets carrying the same device timestamp remain
  filtered.

Install the update through HACS and restart Home Assistant. Existing devices,
configuration entries and entity IDs remain unchanged.
