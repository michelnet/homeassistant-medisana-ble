# Medisana BLE v1.0.3

This patch release prevents blood-pressure history from being duplicated after a
Home Assistant restart.

## Fixed

- The latest restored blood-pressure device timestamp now seeds measurement
  ordering during Home Assistant startup.
- An exact replay of the restored blood-pressure record and older records are
  ignored, while different records sharing a device timestamp remain valid.
- A newer blood-pressure measurement is still accepted immediately.
- Equal TM 750 thermometer indications remain separate accepted measurements.

The HACS validation workflow now runs all checks without ignored categories.

Install the update through HACS and restart Home Assistant. Existing devices,
configuration entries and entity IDs remain unchanged.
