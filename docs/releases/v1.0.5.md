# Medisana BLE v1.0.5

Addresses [issue #1](https://github.com/michelnet/homeassistant-medisana-ble/issues/1).

- Enables Home Assistant long-term statistics with the measurement state class
  for systolic, diastolic and mean arterial pressure, pulse, temperature and
  battery level. User ID and timestamp sensors remain without a state class.
- Documents user-confirmed BU 584 Connect compatibility with an ESPHome Bluetooth
  proxy and its potentially unset device clock.
- Clarifies that date and time can be set locally on the BU-570 and TM 750 connect
  using the device controls, without pairing with VitaDock+.
- Explains that statistics summarize retained values over reception time and do
  not preserve or backfill individual readings at their device timestamps.

Update the integration and restart Home Assistant. Recorder starts collecting
statistics for the enabled measurement sensors; existing entity IDs are preserved.
