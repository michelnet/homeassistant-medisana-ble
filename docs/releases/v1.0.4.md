# Medisana BLE v1.0.4

Removes the fixed `bleak-retry-connector==4.7.0` requirement, which can conflict
with the connector version required by Home Assistant.

The existing `bluetooth_adapters` dependency loads Home Assistant's Bluetooth
integration and its compatible connector before Medisana BLE starts. Test
dependencies also use the connector supplied by the tested Home Assistant
version.

Install the update through HACS or copy the updated component directory, then
restart Home Assistant.
