# Medisana BLE v1.1.0

Adds three BLE measurement profiles alongside blood pressure and temperature,
with automatic discovery, manual setup, sensors and English/German translations.

- **Classic body analysis scales:** adds the `78B2` protocol for BS 410,
  BS 430 connect, BS 440 connect and BS 444 connect. Receives weight, body fat,
  water, muscle, bone mass, basal metabolism and user ID; calculates BMI when
  height is supplied. Setup selects the clock format before synchronization.
  Options provide a user filter and an adjustable connection delay.
- **Pulse oximeters:** adds standard `1822` spot-check and continuous readings
  for PM 100 connect protocol candidates, with oxygen saturation, pulse,
  optional pulse amplitude index and measurement-quality attributes.
- **Glucose meters:** adds an experimental standard `1808` profile for
  MediTouch 2 connect / connect dual protocol candidates. Supports mg/dL and
  mmol/L, sequence-based ordering, matching meal context and optional stored
  record retrieval. Control-solution and fault-marked values remain unknown.
- **Blood pressure:** adds optional synchronization through writable Current
  Time `2A2B`, relevant to additional models such as BU 572 connect. It is
  disabled by default.
- **Device list:** lists 20 models individually with columns for device type,
  model, BLE service, measurements, validation and model notes. Physical tests,
  user reports, simulations and unconfirmed candidates are distinguished.
- **Licensing:** includes the original MIT notice for the classic scale
  adaptation inside the distributed integration directory.

The new profiles have automated simulation coverage but have not yet been
validated on physical devices with this integration. Exact model and firmware
compatibility remains subject to the validation status in the README.

The project manages measurements transferred directly over **BLE GATT**.
WLAN/cloud management and BLE endpoints used solely for WLAN setup are outside
its scope. No decompiled VitaDock implementation or native body-composition
library is included.

Validation: **172 tests and 873 subtests pass** on Home Assistant 2026.11.1;
Ruff checks and formatting pass. The minimum Home Assistant version remains
**2026.9.0**. Existing device configuration and entity IDs are preserved.

Update through the Marketplace or HACS and restart Home Assistant. Existing
devices do not need to be configured again. When adding a classic scale, choose
**2010 for BS 410/444** or **1970 for BS 430/440** during setup, then select the
appropriate user filter in the device options.
