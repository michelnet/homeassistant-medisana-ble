# Medisana BLE 1.2.1

This patch fixes time-zone loading on Home Assistant's event loop, as identified
in the [HACS review](https://github.com/hacs/default/pull/14163#pullrequestreview-5932109396).

All six affected paths now reuse Home Assistant's already loaded default time
zone: device clock synchronization, sensor timestamps, measurement history and
restoration of main and per-user readings. No direct `ZoneInfo` construction
remains in the integration. Changes to Home Assistant's configured time zone
continue to apply without reloading the integration.

Validation: **217 tests and 873 subtests passed** with Home Assistant 2026.11.1.
The 13 new regression cases cover all six paths in winter and summer, preserve
existing aware timestamps, and verify a configured time-zone change. All twelve
seasonal cases reject the previous implementation. Ruff lint/format and
whitespace checks passed.
