# Medisana BLE v1.0.0

The first stable release of **Medisana BLE**, a local Home Assistant integration
for supported Medisana blood pressure monitors and thermometers. No Medisana
account or cloud service is required.

## Supported and hardware-tested devices

- **BU-570 / BU 570 connect:** automatic discovery, setup and blood-pressure
  measurement transfer verified on physical hardware.
- **TM 750 connect:** automatic discovery as `TS42B`, setup and temperature
  measurement transfer verified on physical hardware.

Other Medisana models may use compatible Bluetooth services, but have not been
confirmed.

## Included

- Automatic Bluetooth discovery and manual setup by address and device type.
- Systolic, diastolic and mean arterial pressure, pulse and user ID sensors.
- Temperature readings with Celsius/Fahrenheit and optional temperature type.
- Battery level, device measurement time and Home Assistant reception time.
- Optional blood-pressure user filtering, including user ID `0`.
- Reliable connection sessions, bounded retries and support for multiple records.
- State restoration while battery-powered devices sleep or Home Assistant restarts.
- Manufacturer, model, firmware, serial number and hardware revision when supplied.
- Bundled VitaDock+/Medisana icons and logos.
- English and German setup, option and entity translations.
- HACS README rendering with installation and device documentation.

## Installation

Requires Home Assistant **2026.9.0 or newer**. Add
`https://github.com/michelnet/homeassistant-medisana-ble` as a HACS custom repository,
or copy `custom_components/medisana_ble` into the Home Assistant configuration
folder, then restart Home Assistant.

Users upgrading from `v0.1.0` can install the update in HACS and restart Home
Assistant. Existing `medisana_ble` configuration entries and entity IDs remain
unchanged.

## Notes

The **Last measurement** sensor uses the date and time transmitted by the device.
Ensure the TM 750 connect clock is set correctly after first use or a battery
change; the README links to the official instructions.

Home Assistant loads the bundled brand assets locally. The HACS dashboard icon is
currently affected by [HACS issue #5171](https://github.com/hacs/integration/issues/5171),
which does not affect installation or operation of the integration.

Automated protocol, discovery, configuration, connection and sensor tests pass in
addition to the successful physical-device tests above.
